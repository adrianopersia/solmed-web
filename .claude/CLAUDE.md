# Solmed — Project Instructions

## Stack
- **Framework**: AstroJS v6 (static site generation)
- **Styles**: Tailwind CSS v4 (via `@tailwindcss/vite` — NOT `@astrojs/tailwind`)
- **Language**: TypeScript strict mode
- **Node**: v22

## Folder Structure
```
src/
  components/
    ui/        ← Atoms: Button, Badge, Card, Input
    sections/  ← Page sections: Hero, Features, CTA, Testimonials, FAQ, Contact
    layout/    ← Header, Footer, Nav
  layouts/
    Layout.astro  ← Base layout with SEO meta tags
  pages/         ← File-based routing
  styles/
    global.css   ← @import "tailwindcss" + CSS custom properties
  utils/
    seo.ts       ← buildTitle(), buildCanonicalURL()
    cn.ts        ← Class merging helper
  types/
    index.ts     ← Shared TypeScript interfaces
public/
  fonts/   ← Self-hosted fonts (better performance)
  images/  ← Static images that need no processing
```

## Path Aliases
Always use these — never relative `../../`:
- `@components/*` → `src/components/*`
- `@layouts/*` → `src/layouts/*`
- `@utils/*` → `src/utils/*`
- `@app-types/*` → `src/types/*`  ← NOT `@types` (conflicts with TS namespace)
- `@styles/*` → `src/styles/*`
- `@content/*` → `src/content/*`

## Key Rules

### Components
- `.astro` files for static/layout components (zero JS by default)
- Islands pattern: use `client:visible` for interactive components, never `client:load` unless critical
- Component props use TypeScript `interface Props` inside frontmatter
- Use `class:list` for conditional classes, not string concatenation

### Styles
- Tailwind v4: CSS-first configuration. Custom tokens live in `global.css` under `@layer base`
- Brand colors use CSS custom properties (`var(--color-primary)`) — NOT hardcoded Tailwind colors
- Never use `@apply` for complex utilities — write Tailwind classes inline
- Global styles only in `global.css`, never in scoped `<style>` unless truly component-specific

### SEO
- Every page uses `<Layout>` with `title` and `description` props — never skip them
- `buildTitle()` appends `| Solmed` automatically — pass only the page name
- OG image: place at `public/images/og-default.jpg` (1200×630px)
- Sitemap is auto-generated by `@astrojs/sitemap` — `site` URL must be set in `astro.config.mjs`

### TypeScript
- Use `import type` for type-only imports
- No `any` — use `unknown` if type is truly unknown
- Props interfaces always named `Props` inside the component frontmatter

### Images
- Use Astro's `<Image>` component for all images (automatic optimization + WebP)
- Static decorative images → `public/images/`
- Content images → import directly (processed by Astro)

### Commits
- Conventional commits: `feat:`, `fix:`, `style:`, `refactor:`, `docs:`, `chore:`
- No AI attribution in commits
